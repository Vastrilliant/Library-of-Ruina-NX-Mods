## Requirements 
A modded Nintendo Switch with Atmosphère or an Emulator that supports Atmosphère 
## How to install 
Put the .ips / .pchtxt files in `sdcard/atmosphere/exefs_patches/<Mod Name>/`

## Currently featured 
* No Grind
* Patty Optimization Mod
* Speed Dice Fix Mod
* Skip Intro Mod (personal)

More mods may be uploaded, whenever I feel like it 

Also check out
[Custom Speed Dice Mod](https://github.com/Vastrilliant/LOR-CustomSpeedDie-Switch-Port)

>[!WARNING]
Only works on the latest update (1.0.3), it’ll have no effect on the base 1.0.0 version
